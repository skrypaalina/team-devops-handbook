\# Скрипт резервного копіювання (`backup.sh`)



\## Призначення

Скрипт backup.sh призначений для автоматичного створення стиснених .tar.gz архівів вказаної теки-джерела, їх автоматичної ротації (збереження лише N найновіших копій) та журналювання результатів виконання.



\## Параметри

\* --source <шлях> — Обов'язковий. Шлях до теки, яку необхідно заархівувати.

\* --dest <шлях> — Обов'язковий. Шлях до теки, де зберігатимуться архіви.

\* --keep <N> — Необов'язковий. Кількість найновіших копій для збереження (типово: `5`).

\* --dry-run — Необов'язковий. Режим симуляції: показує заплановані дії без реального створення або видалення архівів.

\* --help — Виводить довідку з описом параметрів та прикладами використання.



\## Приклади запуску



\### 1. Звичайний запуск з параметрами за замовчуванням

```bash

bash lab-03/backup.sh --source "$HOME/my\_project" --dest "$HOME/backups"
