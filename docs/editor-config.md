# Налаштування редактора та Git ignore

## .editorconfig

.editorconfig узгоджує форматування файлів між Windows і macOS.

- root = true зупиняє пошук інших файлів EditorConfig вище за текою проєкту.
- charset = utf-8 задає спільне кодування текстових файлів.
- end_of_line = lf використовує однакове завершення рядків у Windows і macOS.
- insert_final_newline = true додає символ нового рядка в кінці файла.
- trim_trailing_whitespace = true прибирає пробіли наприкінці рядків.
- Для Markdown кінцеві пробіли збережені, бо ними може позначатися перенос рядка.
- Для Markdown і Bash використовуються пробіли замість табуляцій.
- Розмір відступу для Markdown і Bash — два пробіли.

## .gitignore

.gitignore виключає локальні секрети й тимчасові файли зі списку змін Git.

- .env та .env.* ігнорують локальні файли налаштувань; .env.example лишається доступним для спільного використання.
- __pycache__/ і *.py[cod] ігнорують автоматично створені файли Python.
- *.tar.gz ігнорує тестові архіви.
- build/ і dist/ ігнорують теки зі зібраними файлами.
- *.exe, *.dll, *.so, *.dylib, *.out, *.o та *.obj ігнорують поширені виконувані й скомпільовані файли.

Правило .gitignore не перестає відстежувати файл, який уже був доданий до Git раніше.
