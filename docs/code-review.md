# Чек-лист рецензування консольних утиліт

Рецензент перевіряє зміни за пунктами нижче. Для кожного питання має бути можливо відповісти «так» або «ні». Якщо знайдено проблему, залиште коментар із конкретним прикладом і поясненням.

## Призначення та вимоги

- Чи зрозуміло з опису, яку задачу розв'язує утиліта?
- Чи зазначено підтримувану операційну систему або її версію, якщо це важливо?
- Чи перелічено потрібні залежності?
- Чи пояснено, як встановити або підготувати утиліту?

## Запуск і параметри

- Чи можна виконати команду запуску з інструкції?
- Чи зазначено, з якої теки потрібно запускати команду?
- Чи описано кожен параметр, використаний у прикладах?
- Чи вказано обов'язкові параметри та значення за замовчуванням?
- Чи відповідає приклад команди описаному синтаксису?

## Результати й помилки

- Чи відповідає приклад виводу наведеній команді?
- Чи пояснено коди виходу, які повертає утиліта?
- Чи описано, як користувач може побачити довідку?
- Чи зазначено відомі обмеження або типові помилки?

## Зміни в pull request

- Чи відповідають зміни темі pull request?
- Чи не суперечить новий текст іншим розділам довідника?
- Чи можна виконати наведені інструкції без пропущених кроків?
- Чи залишив рецензент хоча б одне змістовне зауваження, якщо є що покращити?

## Як залишити зауваження

Пишіть про конкретну проблему, а не загальну оцінку. Наприклад:

> У прикладі команда використовує --output, але цей параметр не описаний у таблиці. Додайте його пояснення або змініть приклад.
