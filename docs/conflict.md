# Розбір конфлікту злиття в `.editorconfig`

## Причина конфлікту

Дві гілки незалежно змінили той самий ключ у `.editorconfig`. Наприклад, одна гілка задала `indent_size = 2` для Bash, а інша — `indent_size = 4`.

Git не може сам визначити, яке значення відповідає домовленості команди.

## Помилкове розв'язання

Припустімо, команда погодила для Bash два пробіли, але під час розв'язання конфлікту залишили:

```ini
[*.{sh,bash}]
indent_style = space
indent_size = 4
