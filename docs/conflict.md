# Конфлікт у .editorconfig

Дві гілки незалежно додали .editorconfig, але задали різні відступи для Bash.

## Помилкове розв'язання

Якщо залишити indent_size = 4, файл залишиться синтаксично коректним, але редактор використовуватиме чотири пробіли замість погоджених командою двох.

## Правильне розв'язання

У фінальному файлі залишено indent_size = 2 для Bash, як у першій злитій версії. Також прибрано маркери конфлікту й перевірено інші секції. Для Markdown окремо вимкнено обрізання кінцевих пробілів, щоб не прибирати можливі переноси рядків.
